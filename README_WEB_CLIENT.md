# SIP Web客户端使用说明

## 📋 概述

这是一个基于WebRTC的网页版SIP客户端，可以直接在浏览器中拨打和接听电话，支持音频播放。

## 🚀 快速启动

### 1. 启动Web服务器

在服务器上运行：

```bash
cd /home/henry/pjproject
./start_web_client.py
```

或者：

```bash
python3 start_web_client.py
```

### 2. 打开浏览器

在你的**Mac浏览器**中打开：

```
http://<服务器IP>:8080/sip_web_client.html
```

例如：
```
http://8.222.33.80:8080/sip_web_client.html
```

### 3. 开始使用

1. 页面加载后会自动连接SIP服务器
2. 在"目标号码"输入框输入号码（例如：81234567890）
3. 点击"📞 拨号"按钮
4. 通话中点击"📵 挂断"结束通话

## 🔧 重要注意事项

### WebSocket配置

网页客户端需要SIP服务器支持WebSocket协议。当前配置使用：

```javascript
ws://147.139.205.88:5060
```

**如果连接失败，可能需要：**

1. **检查WebSocket端口**
   - 标准SIP端口：5060（UDP/TCP）
   - WebSocket端口可能不同（如：5062、8089等）
   - 请向运营商确认WebSocket端口

2. **修改配置**
   
   编辑 `sip_web_client.html` 文件，找到这一行：
   
   ```javascript
   const CONFIG = {
       server: '147.139.205.88',
       wsPort: 5060,  // ← 修改这里
       sipPort: 5060,
       callerNumber: '6281479242434',
       prefix: '13462'
   };
   ```

3. **使用WSS（加密连接）**
   
   如果服务器要求WSS，修改：
   
   ```javascript
   const wsUri = `wss://${CONFIG.server}:${CONFIG.wsPort}`;
   ```

### 浏览器权限

首次使用时，浏览器会请求麦克风权限，请点击"允许"。

### 防火墙

确保服务器的以下端口可访问：
- 8080（Web服务器）
- 5060（SIP WebSocket）

## 🐛 故障排除

### 1. WebSocket连接失败

**错误日志**: "WebSocket断开连接"

**解决方案**:
- 检查SIP服务器是否支持WebSocket
- 确认WebSocket端口号
- 尝试使用WSS而不是WS
- 检查防火墙设置

### 2. 无法听到声音

**解决方案**:
- 检查浏览器是否允许了麦克风权限
- 检查系统音量设置
- 在浏览器控制台查看是否有错误
- 尝试刷新页面重新连接

### 3. 拨号失败

**解决方案**:
- 确认号码格式正确
- 检查服务器日志
- 确认账号余额充足
- 查看日志框中的详细错误信息

## 📞 测试建议

1. 先测试一个已知可接通的号码
2. 观察日志框中的状态变化
3. 如果振铃但无人接听是正常的
4. 只有接通后（状态显示"通话中"）才能听到声音
